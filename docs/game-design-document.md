## 一、项目概述

### 1.1 游戏简介

| 项目 | 内容 |
|------|------|
| **游戏名称** | 棋跃 |
| **英文名称** | Chess Leap |
| **游戏类型** | 3D平台跳跃跑酷游戏 |
| **游戏主题** | 国际象棋风格 |
| **核心玩法** | 螺旋上升平台跳跃 + Boss战 + 金币收集 |
| **目标平台** | PC (Windows/Mac) |
| **商业模式** | 买断制 |
| **目标用户** | 18-30岁泛用户，追求轻度挑战与成就感 |

### 1.2 游戏愿景

> "在棋盘上跃动，于格子间博弈"

《棋跃》是一款融合国际象棋美学的3D跑酷游戏。玩家操控一枚棋子，在螺旋上升的棋盘格平台上跳跃、战斗、收集。游戏强调**随机挑战**与**核心玩法打磨**，每次游玩都带来不同的挑战体验。

### 1.3 核心卖点

1. **象棋主题美学**：棋子造型角色、棋盘格子地面、简约黑白配色
2. **无限程序化关卡**：基于螺旋算法生成，永不重复
3. **随机挑战机制**：伤害平台、临时平台、Boss追踪
4. **流畅操作手感**：平滑加速减速、精确跳跃控制

## 二、核心玩法循环

### 2.1 游戏目标

玩家需要操控棋子角色，从底部不断向上跳跃，穿越随机生成的平台，最终挑战并击败Boss。

### 2.2 核心循环

```
[开始游戏] → [跳跃移动] → [躲避危险] → [收集金币] → [战斗Boss] → [继续上升]
     ↑                                                            ↓
     └────────────────────── [失败重来] ←──────────────────────────┘
```

### 2.3 核心操作

| 操作 | 输入 | 描述 |
|------|------|------|
| 移动 | WASD / 方向键 | 相对摄像机方向移动 |
| 跳跃 | 空格键 | 在地面上起跳 |
| 暂停 | ESC | 暂停/继续游戏 |

## 三、游戏系统设计

### 3.1 平台系统

#### 3.1.1 平台生成机制

- **生成方式**：围绕中心点螺旋上升
- **螺旋参数**：
  - 半径：6单位
  - 每平台上升高度：1.5单位
  - 每平台旋转角度：45°
- **随机缩放**：
  - 宽度(X)：3-7单位
  - 深度(Z)：2-4单位
  - 高度(Y)：0.5单位（固定）

#### 3.1.2 平台类型

| 类型 | 视觉 | 行为 | 概率 |
|------|------|------|------|
| **普通平台** | 默认材质 | 安全着陆 | 80% |
| **伤害平台** | 红色材质 | 持续造成1点伤害/0.5秒 | 10% |
| **临时平台** | 半透明材质 | 3秒后自动消失 | 10% |

#### 3.1.3 平台回收

- 玩家后方超过15单位的平台自动回收
- 平台回收时同步回收关联金币
- 使用对象池优化性能

### 3.2 玩家系统

#### 3.2.1 移动控制

- **最大速度**：9单位/秒
- **加速曲线**：指数函数 (Mathf.Exp)
- **减速曲线**：对数函数 (Mathf.Log)
- **转向处理**：相反方向时先减速后加速

#### 3.2.2 跳跃机制

- **跳跃速度**：8单位/秒（垂直）
- **重力加速度**：20单位/秒²
- **地面检测**：OverlapBox检测
- **跳跃冷却**：依赖地面检测（落地即可跳）

#### 3.2.3 受伤系统

- **受伤冷却**：1秒（防止连续碰撞）
- **受伤伤害**：10点
- **护盾保护**：药水系统可抵挡一次伤害

### 3.3 金币系统

#### 3.3.1 生成规则

- 生成概率：60%
- 生成位置：平台表面随机位置
- 边缘留空：0.5单位
- 高度偏移：平台上方1单位

#### 3.3.2 金币池管理

- 使用对象池预加载
- 平台回收时同步回收金币
- 金币收集触发UI更新

### 3.4 Boss系统

#### 3.4.1 Boss行为

- **触发方式**：玩家到达特定高度触发
- **追踪模式**：向玩家位置移动
- **移动速度**：3单位/秒
- **攻击方式**：接触伤害

#### 3.4.2 Boss血条

- 显示Boss生命值
- 受伤时更新UI
- 死亡时触发结算

### 3.5 商店系统

#### 3.5.1 NPC交互

- 与商人NPC对话
- 消耗金币购买药水

#### 3.5.2 药水系统

| 药水类型 | 效果 | 持续时间 |
|----------|------|----------|
| 生命药水 | 恢复生命值 | 即时 |
| 护盾药水 | 抵挡下一次伤害 | 永久直到触发 |
| 速度药水 | 提升移动速度 | 10秒 |

### 3.6 UI系统

#### 3.6.1 游戏UI

- 生命值条：玩家血量显示
- 金币计数：当前金币数量
- Boss血条：Boss生命值（战斗中）

#### 3.6.2 菜单系统

- **主菜单**：开始游戏
- **暂停菜单**：继续、返回主界面
- **死亡界面**：重新开始、返回主界面

│   ├── CoinSpawner.cs       # 金币生成

## 七、关卡设计

### 7.1 关卡结构

```
[起始平台] → [教学区：简单平台] → [挑战区：混合平台] → [Boss区]
     ↓              ↓                    ↓                ↓
  简单跳跃      伤害平台出现       临时平台+密集生成     Boss战
```

### 7.2 难度曲线

| 阶段 | 平台数量 | 伤害平台 | 临时平台 | Boss |
|------|----------|----------|----------|------|
| 前期 | 密集 | 10% | 5% | 无 |
| 中期 | 中等 | 15% | 10% | 无 |
| 后期 | 稀疏 | 20% | 15% | 有 |

### 7.3 Boss设计

- **出现位置**：玩家达到一定高度
- **战斗方式**：持续追踪 + 接触伤害
- **击败条件**：消耗Boss全部生命值
